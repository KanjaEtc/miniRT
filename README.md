**Dossier pseudo-code** : ce sont des ebauches de fonctions. L'idee est d'avoir un squelette du projet et une bonne vue d'ensemble avant de commencer a coder vraiment. Tout ce qui est dans ces fichiers doit etre retravaille, ameliore, complete, etc.

**Dossier ressources** : contient les explications necessaires en termes de maths. Formules + explications complementaires. Tous les fichiers qu'il contient doivent etre completes, ameliores, reverifies au moindre doute. C'est une sorte de README divise en plusieurs morceaux.
